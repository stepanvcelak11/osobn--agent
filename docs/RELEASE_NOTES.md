První verze osobního offline agenta pro iPhone.

**Instalace:** stáhni `OsobniAgent-unsigned.ipa` a nainstaluj přes Sideloadly / AltStore (viz [docs/INSTALACE.md](https://github.com/stepanvcelak11/osobn--agent/blob/main/docs/INSTALACE.md)). Pak v aplikaci nahraj modely (Nastavení → Modely).

Obsahuje: lokální chat (llama.cpp), nástroje a šifrovanou databázi (SQLCipher), připomínky a notifikace, hlas (whisper.cpp + české hlasy iOS), domovský přehled se shrnutím, sémantické hledání, šifrované zálohy, test modelu přímo v telefonu.
